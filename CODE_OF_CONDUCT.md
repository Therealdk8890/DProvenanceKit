# Code of Conduct

## Our commitment

We want DProvenanceKit to be a respectful, constructive place for contributors, maintainers, users and reviewers. Participants are expected to communicate professionally, assume good faith, keep criticism focused on technical work rather than people, and respect different backgrounds and levels of experience.

## Unacceptable behavior

Harassment, discrimination, personal attacks, threats, deliberate disruption, doxxing, sexualized language or attention, and publishing private or confidential information without permission.

Security-sensitive discussion follows `SECURITY.md`; do not post exploit details in public issues or pull requests.

## Maintainer response

Maintainers may remove comments, close discussions, reject contributions, or restrict participation when needed to keep project spaces safe and constructive.

## Scope

This code applies in all project spaces (issues, pull requests, discussions, reviews) and when someone is representing the project elsewhere.

## Reporting

Report conduct concerns privately to the maintainer through the contact listed on the repository owner's GitHub profile. Reports are handled confidentially. For security vulnerabilities, use the private process in `SECURITY.md`.

This document is adapted from the spirit of the [Contributor Covenant](https://www.contributor-covenant.org/), version 2.1.
